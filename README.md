## 📚 Text Search Indexer – Implementation

The project was implemented through the following major stages:

1. **Tokenize and Normalize Text** – Convert input text into standardized lowercase words and remove unwanted characters.
2. **Build Word-to-Line Index** – Map each unique word to the lines where it occurs.
3. **Single Keyword Search** – Retrieve line numbers associated with a specified keyword.
4. **Multi-Keyword AND Search** – Find lines containing all requested keywords.
5. **Occurrence Count Summary** – Provide keyword-frequency information for the search results.
